# Component Rules

- Use **shadcn/ui** for all UI components
- Use **Tailwind CSS** for styling — no raw CSS files
- TypeScript strict mode everywhere
- Server components by default, 'use client' only when needed
- All components must be responsive (mobile-first)

## Design Direction: BitCoil
- **Theme**: Dark, crypto-native, premium feel
- **Primary accent**: BTC Orange `#F7931A`
- **Secondary**: Cool grays and deep blacks
- **Typography**: Use a distinctive monospace/tech font for numbers, clean sans-serif for body
- **Vibe**: Professional DeFi dashboard — not flashy memecoin, but not boring institutional either
- **Animations**: Subtle — smooth transitions, gentle glows on hover, number counters for leverage stats
