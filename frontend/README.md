# BitCoil Frontend

Next.js frontend for BitCoil — automated BTC leverage looping vault on Starknet.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- **Next.js 15** (App Router, TypeScript)
- **starknet-react** + starknet.js for wallet and contract interaction
- **shadcn/ui** + Tailwind CSS v4 for UI
- **Starknet Sepolia** testnet
